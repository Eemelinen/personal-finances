# FIN-018: Income vs expenses & cash flow

**Milestone:** M3 Dashboard · **Status:** Todo · **Depends on:** FIN-014

## Description

Show whether I'm saving money month by month.

## Acceptance criteria

- [ ] `/reports/cash-flow`: monthly bars of income vs expenses for the last 12 months, with a net line
- [ ] Savings rate per month: (income − expenses) / income
- [ ] Year-to-date totals and monthly averages
- [ ] Transfers between own accounts excluded
- [ ] Summary tile on the dashboard: this month's income, expenses and net so far
