# FIN-021: Monthly budgets (optional)

**Milestone:** M3 Dashboard · **Status:** Todo · **Depends on:** FIN-017

## Description

Set a monthly spending limit per category and track progress during the month.

## Acceptance criteria

- [ ] `budgets` table: category, monthly amount, valid-from month
- [ ] `/budgets`: progress bars per category (spent / budget) for the current month, colored by pace
- [ ] Suggested budget = the 6-month average per category
- [ ] Dashboard widget showing categories over budget
